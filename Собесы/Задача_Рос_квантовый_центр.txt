Необходимо написать bash скрипт, который автоматически создает виртуальную машину с заданной конфигурацией на сервисе VK cloud, скрипт может использовать openstack cli https://mcs.mail.ru/docs/ru/manage/tools-for-using-services/openstack-cli#.

Требования к скрипту:
- Параметры виртуальной машины скрипт должен принимать через аргументы командной строки;
- Если какой-то параметр не указан, его значение выставляется по умолчанию в соответствии с минимальной конфигурацией (самой дешевой);
- Параметры должны иметь полную и краткую форму (например -h и —help);
- Скрипт должен возвращать документацию об использовании при передаче в него —help, -h и завершаться с нулевым кодом;
- При передаче не корректного аргумента скрипт должен выдавать сообщение об ошибке, документацию и завершаться с кодом 1;
- Скрипт должен проверять наличие всех необходимых инструментов (зависимостей) и выдавать соответствующее сообщение об ошибке при их отсутствии, при этом должен завершаться с не нулевым кодом.
- Скрипт должен сохранять данные необходимые для подключения к виртуальной машине в отдельный конфигурационный файл. Имя файла можно передавать как аргумент командной строки или через переменную окружения. При не указанном имени файла, скрипт должен создать конфигурационный файл со стандартным именем в дирректории самого скрипта.

Регистраци на VKCloud безплатная, после регистрации можно получить 3000р на пробный период использования
